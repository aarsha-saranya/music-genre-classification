# Music Genre Classification

A simple Python project that uses MFCC audio features and k-nearest neighbors to classify music genres.

## Project structure

- `app.py` - Streamlit web application for uploading audio files and getting genre predictions.
- `music_genre.py` - Builds a dataset from WAV files in the `genres` folder, extracts MFCC features, and evaluates classification accuracy using a random train/test split.
- `test.py` - Loads the serialized dataset from `my.dat`, converts a new audio file to WAV if needed, extracts features, and predicts the genre using k-NN.
- `genre_utils.py` - Shared utility functions for feature extraction, dataset loading/building, and genre prediction used by both `test.py` and `app.py`.
- `genres/` - Contains genre directories and example audio files used to build the dataset.
- `my.dat` - Serialized feature dataset generated by `music_genre.py`.
- `label_map.pkl` - Pickled dictionary mapping genre labels to genre names.

## Requirements

- Python 3
- `numpy`
- `scipy`
- `python_speech_features`
- `imageio_ffmpeg`
- `streamlit`

## Usage

1. Generate the dataset and evaluate a basic classifier:

```bash
python music_genre.py
```

This script scans `F:\music-genre-classification\genres`, computes MFCC features for each WAV file, saves feature tuples into `my.dat`, and prints training/test sizes plus accuracy.

2. Predict the genre of a single audio file:

```bash
python test.py path\to\audio.wav
```

`test.py` supports WAV and common compressed input formats such as MP3, FLAC, OGG, M4A, AAC, and WMA by converting them to WAV with FFmpeg.

3. Run the interactive Streamlit web app:

```bash
.\.venv\Scripts\python.exe -m streamlit run app.py
```

The Streamlit app (`app.py`) provides a user-friendly interface to:
- Upload audio files in multiple formats (WAV, MP3, FLAC, OGG, M4A, AAC, WMA)
- Get instant genre predictions using the trained k-NN model
- Automatically builds/validates the dataset on first run if needed

Open your browser to `http://localhost:8501` after running the command above.

## How it works

- `music_genre.py`:
  - walks the `genres` dataset folder
  - loads each WAV file
  - computes MFCC features and their mean/covariance
  - serializes feature tuples `(mean_vector, covariance, label)` into `my.dat`
  - saves the genre label mapping to `label_map.pkl`
  - splits records into training/test sets and evaluates k-NN accuracy

- `test.py` and `app.py`:
  - load the serialized dataset from `my.dat` and genre mapping from `label_map.pkl`
  - convert provided audio files to WAV if necessary using FFmpeg
  - compute MFCC features for the input file
  - compare the example to stored dataset items using a covariance-aware distance metric
  - predict the genre label by majority vote among the 5 nearest neighbors

- `genre_utils.py`:
  - Provides shared functions for loading/building datasets, computing features, and making predictions
  - Automatically rebuilds the dataset if it becomes corrupted or incomplete
  - Handles audio format conversion and MFCC feature extraction

## Notes

- The dataset is automatically built on first run if `my.dat` or `label_map.pkl` are missing or corrupted.
- Supports 10 genres: blues, classical, country, disco, hip-hop, jazz, metal, pop, reggae, rock.
- The classifier uses a k-NN approach with k=5 neighbors.
- Audio features are based on MFCC (Mel-Frequency Cepstral Coefficients) with 13 coefficients.
- Distance metric uses covariance-aware Mahalanobis distance for robustness.
- FFmpeg is required for converting compressed audio formats (MP3, FLAC, OGG, etc.) to WAV.
